# Homelab — Cybersecurity Lab

## Overview
A personal cybersecurity homelab built from donated hardware,
designed for practicing penetration testing, network monitoring,
and defensive security techniques.

## Network Architecture
- **Firewall:** pfSense on HP Slimline 450
- **Hypervisor:** Proxmox VE on HP ProDesk 600 G1
- **Attacker:** Kali Linux on Toshiba C55
- **Target:** Metasploitable 2 on ASUS X540S
- **Monitoring:** Security Onion on Toshiba L875D

## Skills Practiced
- Network segmentation and firewall configuration
- Penetration testing with Kali Linux and Metasploit
- Intrusion detection with Security Onion
- Virtualization with Proxmox
